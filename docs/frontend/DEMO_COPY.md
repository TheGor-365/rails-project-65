# Демо-описания Classifieds

Публичный каталог включает локально подготовленные примеры объявлений с фотографиями.
Текст `Lorem ipsum` записан в базе development и **не содержится** в `db/seeds.rb`.
Не создавайте повторно записи и не запускайте `db:fixtures:load` на существующей
development-базе: это может затронуть данные.

## Безопасный порядок

После получения ветки с задачей:

```bash
ASDF_RUBY_VERSION=3.4.12 bin/rails demo:descriptions
```

По умолчанию команда лишь выводит ID, название и новый текст; БД не меняется.
Она ищет только заранее известные названия и описания, **начинающиеся с
`Lorem ipsum`**. Другие записи, заголовки, изображения, состояния, даты и
владельцы не затрагиваются.

Проверьте результат предварительного просмотра, затем отдельно выполните:

```bash
APPLY=1 ASDF_RUBY_VERSION=3.4.12 bin/rails demo:descriptions
```

Перед обновлением исходные описания сохраняются в CSV внутри
`tmp/db-backups/` (Git игнорирует `tmp/`).
Повторный запуск безопасен для уже обновлённых записей: их текст больше не
начинается с `Lorem ipsum`. В production эта задача заблокирована.

## Редакционная политика

Тексты предназначены для **демонстрационного каталога**, а не подтверждают
реальное предложение, актуальные цены, наличие товаров или условия услуг.
В них нет выдуманных контактов, моделей, гарантий, стоимости или отзывов.

Объявления с неизвестными названиями и нераспознанными демонстрационными
описаниями задача намеренно пропускает: для них требуется отдельный просмотр.
